# Core Concepts Applied
# -------------------------------

# 1. Clarity and Readability:
#    The pseudocode and flowchart explanations are written in plain, understandable English.
#    Each step follows a logical order, making the process easy to grasp even for beginners in programming.

# 2. Precision:
#    The instructions are clearly defined without ambiguity.
#    For instance, the temperature conversion formula is stated exactly as:
#    (celsius * 9/5) + 32
#    This ensures there is no confusion about its implementation.

# 3. Abstraction:
#    The focus is on logical thinking (e.g., “check if a number is even”)
#    rather than programming syntax (like if(number % 2 == 0)).
#    This highlights problem-solving over coding specifics.


# -------------------------------
# Pseudocode Conventions
# -------------------------------

# - Keywords: Control structure keywords (START, END, READ, PRINT, IF, ELSE, ENDIF, AND)
#   are written in uppercase for emphasis.
# - Indentation: Proper indentation is used to represent nesting inside blocks such as IF statements.


# -------------------------------
# Flowchart Symbols
# -------------------------------

# - Oval: Used for Start and End points.
# - Parallelogram: Represents input and output actions (READ, PRINT).
# - Rectangle: Used for processes like calculations or assignments.
# - Diamond: Represents decision points, such as conditional IF statements.


# -------------------------------
# Basic Structures
# -------------------------------

# - Sequence: Problems 1 and 4 follow a simple, step-by-step order.
# - Selection (Decision-Making): Problems 2 and 3 use IF, ELSE IF, and ELSE for branching logic.
#   In the flowchart, these are shown with diamond shapes.
# - Input/Output: Consistently uses READ for input and PRINT for output.
# - Assignment: Represented using the '=' operator (e.g., area = length * width).
